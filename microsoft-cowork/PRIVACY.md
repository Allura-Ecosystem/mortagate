# Privacy Notice — Development Package

This repository package is a development artifact, not a deployed service.

The skills-only release does not include a remote connector, credentials, telemetry endpoint, or storage service. Cowork and Microsoft 365 tenant controls govern files and conversations used in a deployment.

Before any production deployment, the sponsoring organization must publish its own privacy notice, complete data-protection review, configure Microsoft Purview and tenant access controls, and approve any connected data source.
