# Pilot feedback

Per US-6.4 ruling 3A (Sabir, 2026-08-28): pilot feedback lands here — one file per
pilot-cohort member, using the template at the bottom of
`../US-6.4-pilot-decisions-brief.md`.

Naming convention: `feedback-<name>-<YYYY-MM-DD>.md`.

When every cohort member has a file here, US-6.8's first AC ("feedback collected
from every pilot-cohort member, not just volunteers") is provable — the loop can
count files, not anecdotes.
